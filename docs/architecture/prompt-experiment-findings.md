# Prompt Experiment Findings

Append-only record of what prompt experiments proved. Scores live in prompt-score-ledger.md.

## Principles generalize where rule lists recite (2026-08-07)

Three second-person Principles absorbed ten always-on communication Rules with no measured loss (103 vs 101 of 120).

- The stated belief produced behavior no Rule requested: only the Principles-governed responder added what the Architect cannot read off the diff ("the rename is name-only, no stale references remain"). The full-rule-list responder echoed the task back.
- One absorption failed: the transcript ban did not hold as a Principle clause. The Principles-governed responder cited line numbers and test-function names as proof of work and lost that scenario on it. "Report the result, never the transcript" stays an explicit Rule.
- The control (no communication prompt) matched on completeness and lost 10+ points on signal: narration, aphorisms, pasted output, trailing file appendices. The always-on prose earns its place.

## Task framing, not formatting words, causes borderless tables (2026-08-22)

Ten Opus architect-agent dispatches on one research task in creator-income-blueprint, byte-identical except one clause. Tables appeared 3 of 10, and every occurrence traces to the clause.

- A Goal that asks the same facts about every item in a list tabled 2 of 2, on both the architect and catch-all personas, with whole clauses in the cells. The same data asked pairwise ("map each class to its responsibility") stayed a nested list.
- Formatting clauses never tabled, 0 of 7: control, "format for scanning", "concise and structured", "summarize components and relationships", "structured report with clear sections", "extremely compact, scanned in ten seconds".
- Quoting /show-me's table-permission rule in an otherwise clean brief tabled 1 of 1. Naming tables primes tables, restriction included.
- Three cure wordings each returned the diagram and the annotated file tree with zero tables: the formats spelled out inline, the /show-me file named by path, and /show-me named as a Skill. The named-Skill form is the convention and became delegate's "Require the class diagram and the file tree in the Goal" rule; the class diagram was defined in /show-me the same day.
