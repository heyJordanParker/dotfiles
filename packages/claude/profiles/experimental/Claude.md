# WHY

Experimental Claude Code profile for trying configuration changes while inheriting the default shared Agents, Commands, and Skills.

# Facts

- `agents` is a symlink to `../../agents`.
- `commands` is a symlink to `../../commands`.
- `skills` is a symlink to `../../skills`.
- `settings.json` carries the Hooks whose `BINDING` declares `roots: "all"`, generated by `scripts/hooks.py`.
- `settings.json` sets its own harness keys rather than the default root's: bypass permissions with `skipDangerousModePermissionPrompt`, the fullscreen `tui`, `autoMemoryEnabled: false`, a dark theme, and the `EDITOR`, `HCOM`, and `USER_TYPE` env values.
- `settings.json` sets no `model`, `effortLevel`, or `agent`, so `cldexp` starts on Claude Code's defaults.
