# Broadcast

A single send to a list — a newsletter issue, an announcement, a one-off nudge. It stands alone; it does not compound across a series, so the whole job lands in one email.

- **Job:** earn one open and drive one action from a warm list in a single send.
- **Stage:** your own list — usually solution-aware to most-aware. Open on what they already know, not a from-scratch build.
- **Shape:** one idea, one CTA. Open on the reason to read this issue now; the value is the body; the ask is single and clear.
- **Moves:**
  - The subject decides the open — front-load the one thing this issue gives.
  - Give the value before the ask; a broadcast that is all ask trains the list to stop opening.
  - One CTA. A newsletter with three links splits the click and converts none.
- **Mistake:** a digest of five topics with no single next step, or an ask with no value delivered first.
