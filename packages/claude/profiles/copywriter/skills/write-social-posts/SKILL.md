# Write Social Posts

One Process: organic content does not inherit conversion-page logic — there is no controlled frame and no hard CTA, so the hook does the work a whole page does elsewhere and the conversion is the reply, the save, the ranking.

## 1. Pick the format and load its one reference

Brief.md names the format. Load only that format's reference and write to it.

- Tweet — one self-contained short message (X) → references/tweet.md
- Thread — a chain of tweets (X) → references/thread.md
- LinkedIn post — mid-length, never blog-style → references/linkedin-post.md
- Carousel — a slide sequence (Instagram/LinkedIn), copy per slide → references/carousel.md
- Image post — an image plus a caption → references/image-post.md
- Story — ephemeral frames, copy per frame → references/story.md
- Reel — on-screen text and caption → references/reel.md

## 2. Write native to the platform

Write the piece to the format reference's rules. Each format is written to its own feed, not interchangeable.

### Write under the plan's files and the product's Voice.md
Write under the plan's Reader.md, Brief.md, and Proof.md, and the product's Voice.md, which names the WHO speaking; the post carries that voice as a specific human point of view, never a corporate brand voice, and speaks to Reader.md's Audience — the named buyer the hook's angle targets, never a generic feed. Never assume an offer mechanism the owner has not approved, and never invent a number, result, or quote.

### Specify the design for a visual format
A carousel, image post, story, or reel is text plus a visual. Write the on-screen or on-image text and the caption to a stated design requirement, so the text and the image are built as one piece (design), never copy handed off to a picture chosen later.

### Hold the bar
Fifth-grade words, one read. No metaphors, no metaphorical verbs. Be specific — every figure traces to a fact or graded source. Punctuate for consumption. Never narrate the reader — the post carries a point of view, it does not assert what the reader does, feels, or has.

### Deliver options on the hook
Give 2-3 distinct hooks, each labeled with the angle it plays to.

## 3. Keep links out of the post

### No link sits in the post
No social post carries a link in its body. A link goes in a followup comment or reply, or in a hand-raiser.
Evidence (owner, verbatim): "all social media posts avoid links" and "links usually go in followup comments; or in handraisers".

## 4. Use a hand-raiser to route the ask

### A hand-raiser trades an action for a thing
A hand-raiser is a do: comment or DM a phrase to get a thing.
Evidence (owner, verbatim): "hand-raisers are do – comment/dm 'xyz' phrase to get xyz thing".

Verification: the post is written native to its named format, the hook leads, no link sits in the post body, and no unpermitted fact appears.
