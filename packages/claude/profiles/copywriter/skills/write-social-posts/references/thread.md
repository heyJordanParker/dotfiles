# Thread

A thread is a chain of tweets on X. A hook tweet opens it, standalone value tweets carry it, a close ends it.

### Open on a hook tweet that could stand alone
The first tweet earns the read for the whole chain. It carries the sharpest claim or the most useful specific, and works even if no one taps through.

### Make each tweet a standalone one-idea value tweet
Run 5-7 value tweets between the hook and the close, each carrying one idea and readable on its own. A reader landing on any single tweet gets something whole.

### Close by asking for the reply
End on a close that invites the reply. The question rule binds to a single tweet, never the thread as a whole — the thread's close may ask.
