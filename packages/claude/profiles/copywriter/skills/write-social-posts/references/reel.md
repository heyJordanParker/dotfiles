# Reel

A reel is a short video. Write the on-screen text and the caption.

### Open the on-screen text on a hook
The on-screen text is what the muted feed reads first. The opening frame carries the hook — one idea, a reason to keep watching.

### Let the caption extend, not repeat
The caption carries the context and the ask beside the video, not a restatement of the on-screen text.

### The spoken script is not written here
A spoken script, when one exists, comes from write-video-script. This skill writes the on-screen text and the caption only.
