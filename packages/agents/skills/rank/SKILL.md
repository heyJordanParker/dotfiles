# Rank

## 1. Pick the scores

Pick 3-5 scores that best quantify this decision.

## 2. Score every option

Score each option out of 100 on every score. The option's own number is the average.

## 3. Present worst to best

### Write every option the same way
Never: a table, a short form of a score name, or a score with no name.

Template:
  ## Option Title (74/100)
  The big idea, alone in this paragraph.

  Score Name 1: 82/100 • Score Name 2: 71/100 • Score Name 3: 69/100

  Biggest change: what this option changes most.

  Everything else, in paragraphs.
