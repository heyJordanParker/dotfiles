# WHY

Karabiner keyboard configuration generated from TypeScript so the committed keyboard profile follows one readable source.

# Facts

- This package is a private Bun package named `karabiner`.
- `bun run build` runs `bun run src/index.ts`.
- `src/index.ts` uses `karabiner.ts`.
- `src/index.ts` writes the `Default profile` Karabiner profile.
- The current source defines one `caps_lock pressed` layer from `caps_lock`.
- `karabiner.json` is the generated Karabiner configuration.
- `docs/karabiner-ts-reference.md` is the local `karabiner.ts` Application Programming Interface Reference.
