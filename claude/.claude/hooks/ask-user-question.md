Before asking a question:

- Research first. Only ask if <90% confident after checking codebase and docs.
- If over 90% confident, decide yourself and mention it in the question text.
- Make questions self-contained. User should answer without reading files, a plan you created, or anything else you said. Add details, code examples, annotated file trees, and anything else necessary to explain the issue effectively.
- Provide 4+ options. Yes/no wastes the tool.
- One decision per question. Don't batch.

Bad: "projects probably don't have Claude.md files" (guess)
Good: "found 63 Claude.md files via find" (verified)

Bad: "does this text work?" (one option for approval)
Good: four wording options with tradeoffs (real choices)
